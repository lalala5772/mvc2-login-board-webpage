# Java MVC2 Login & Board Practice

Java Servlet/JSP와 JDBC를 활용하여 회원 관리 및 게시판 기능을 구현한 웹 애플리케이션 실습 프로젝트임.

MVC2 구조를 바탕으로 요청 처리, 비즈니스 로직과 데이터베이스 접근을 분리하고, Oracle DB와 연동하여 웹 애플리케이션의 기본 동작을 구현함.

## 주요 기능

- **회원 관리**: 회원가입, 로그인, 로그아웃 및 아이디 중복 확인
- **게시판**: 게시글 작성, 목록 조회, 상세 조회, 수정 및 삭제
- **댓글**: 댓글 작성, 조회, 수정 및 삭제
- **파일 첨부**: 게시글 작성 시 파일 업로드 및 파일 정보 저장
- **페이징**: 게시글 목록의 페이지별 조회 및 페이지 네비게이션
- **세션 관리**: 로그인 사용자 정보의 세션 저장 및 로그아웃 시 세션 무효화

## 기술 스택

- **Language**: Java
- **Backend**: Java Servlet, JSP
- **Database**: Oracle Database
- **Database Access**: JDBC, PreparedStatement
- **View**: JSP, JSTL
- **File Upload**: COS MultipartRequest

## MVC2 구조

요청 처리와 화면 출력을 분리하고, DAO를 통해 데이터베이스에 접근하도록 구성함.

- **Controller**: Servlet을 통해 클라이언트 요청을 처리하고 필요한 데이터를 조회하거나 저장한 뒤 JSP로 전달함.
- **DAO**: JDBC를 사용하여 회원, 게시글, 댓글 등의 데이터에 접근함.
- **DTO**: 회원, 게시글, 댓글 및 파일 정보를 객체로 관리함.
- **View**: JSP를 통해 데이터 조회 결과를 화면에 출력하고 사용자 입력을 처리함.

## 주요 구현 내용

### 1. 회원 관리

- 회원가입 정보의 데이터베이스 저장
- 아이디 중복 여부 확인
- 아이디와 비밀번호를 이용한 로그인 처리
- HttpSession을 활용한 로그인 상태 관리

### 2. 게시판 및 페이징

- 게시글 CRUD 기능 구현
- Oracle SQL의 `ROW_NUMBER()`를 활용한 페이지별 게시글 조회
- 전체 게시글 수를 기준으로 페이지 네비게이션 구성

### 3. 댓글 및 파일 첨부

- 게시글과 연결된 댓글의 등록 및 조회
- 댓글 수정 및 삭제
- COS 라이브러리를 활용한 파일 업로드
- 업로드 파일명과 저장 파일명을 별도 관리

## 학습 목표

- Java Servlet의 요청 처리와 JSP의 화면 출력 방식 이해
- MVC2 패턴을 활용한 Controller, DAO, DTO의 역할 분리
- JDBC와 PreparedStatement를 활용한 Oracle DB 연동
- 세션을 활용한 로그인 상태 관리
- 게시판 CRUD, 페이징 및 파일 업로드 구현 경험

## 실행 환경 및 설정

- Servlet/JSP를 지원하는 Java 웹 애플리케이션 서버 필요
- Oracle Database 및 프로젝트에서 사용하는 테이블과 시퀀스 구성 필요
- JNDI 데이터 소스 `java:comp/env/jdbc/orcl` 설정 필요
- 파일 업로드 경로 및 데이터베이스 연결 설정 확인 필요

※ 데이터베이스 스키마, 서버 설정 및 실행 환경에 따라 별도 구성이 필요할 수 있음.

## 프로젝트 성격

Java 웹 개발의 기초를 익히기 위한 실습 프로젝트로, Servlet/JSP 기반 MVC2 구조와 JDBC를 이용한 데이터베이스 연동, 기본적인 게시판 기능 구현에 중점을 둠.
